# OWASP Juice Shop – Web Application Security Assessment

A controlled web application security assessment of OWASP Juice Shop performed in a local lab environment using Kali Linux.

## Objective

The objective of this assessment was to identify and document common web application security weaknesses through reconnaissance, manual testing, request analysis, and vulnerability validation.

## Environment

- Kali Linux
- OWASP Juice Shop
- Burp Suite
- Nmap
- Web Browser
- VMware

## Methodology

The assessment followed a structured workflow:

Reconnaissance
→ Service Enumeration
→ Web Application Analysis
→ Vulnerability Testing
→ Evidence Collection
→ Finding Documentation

## Activities Performed

- Host and service reconnaissance
- HTTP service identification
- Web application analysis
- Manual request inspection and manipulation
- Vulnerability validation
- Evidence collection using screenshots
