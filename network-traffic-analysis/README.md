
# Network Traffic Analysis & Threat Detection Lab

A controlled network traffic analysis lab using Kali Linux, Metasploitable 2, and Wireshark to examine network communication and identify relevant traffic patterns.

## Objective

The objective of this project was to understand how network communication appears at the packet level and develop practical experience in traffic capture, filtering, protocol analysis, and security-oriented investigation.

## Environment

- Kali Linux
- Metasploitable 2
- Wireshark
- VMware
- Isolated virtual network

## Methodology

The analysis followed a packet investigation workflow:

Traffic Generation
→ Packet Capture
→ Display Filtering
→ Protocol Identification
→ Source/Destination Analysis
→ Packet-Level Inspection
→ Security Interpretation

## Experiments

The project examined several types of network traffic, including:

- TCP connection establishment
- HTTP communication
- DNS queries and responses
- SSH communication
- TCP flags and packet behavior
- Source and destination analysis

## Evidence

Packet captures and screenshots are included in the repository to demonstrate the observations made during the experiments.
