# Report 6 — SSH Authentication Monitoring and Log Analysis using Splunk

## Overview

This laboratory demonstrates a security monitoring workflow using **Kali Linux, Metasploitable 2, SSH authentication logs, and Splunk Enterprise**.

Controlled failed and successful SSH authentication events were generated, verified in `/var/log/auth.log`, imported into Splunk, and searched using Splunk Processing Language (SPL).

The purpose of this lab was to understand how authentication activity generated by an operating system can be collected, indexed, searched, and analyzed through a centralized security monitoring platform.

> **Note:** This assessment was performed in an isolated laboratory environment. The authentication events were deliberately generated for testing and should not be described as evidence of a real compromise.
